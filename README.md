# 🌐 Portfolio Website

A modern and responsive personal portfolio website to showcase projects, work experience, and contact information.  

---

## 🚀 Features
- Fully responsive design  
- Clean and minimal UI  
- Smooth animations and transitions  
- Project showcase section  
- Contact form with direct reach  

---

## 🛠️ Built With
- React + TypeScript  
- Tailwind CSS  
- Vite  

---

## ⚡ Getting Started

```bash
# Clone the repository
git clone https://github.com/your-username/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run development server
npm run dev
